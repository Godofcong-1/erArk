# 计划模板

本模板从 `plan/done/` 的已完成计划（plan_01 ~ plan_11）中提炼，供新建计划时直接复制套用。

## 使用说明

### 命名与生命周期

- 文件命名：`plan_NN_短标题.md`（NN 为顺延的两位编号）
- 新计划放在 **`plan/wait/`**；实施完成、测试通过并补齐执行记录后，移入 **`plan/done/`** 归档
- 计划的前置调研草稿（如有）可放 `plan/wait/NN_tem.md`，正式计划中引用（先例：plan_10）

### 单文件还是双文件

- **默认单文件**：一份 `plan_NN_短标题.md` 包含从目标到执行记录的全部章节
- **大型计划拆双文件**（先例：plan_10。适用于：改动 15+ 文件、涉及存档数据迁移、预期多轮追加需求）：
  - `plan_NN_标题_方案.md` —— 只写"为什么与是什么"：需求（含编号的追加需求列表）、现状调查、设计决策、数据结构设计、风险、范围外、各轮追加调整的设计（§8.x 顺延）
  - `plan_NN_标题_实施步骤与记录.md` —— 只写"怎么做、怎么验、怎么回滚"：改动文件清单、详细改动步骤、构建、验证清单、回滚、实施过程记录（§6.x 顺延）
  - 两文件文件顶部各用一段 blockquote 声明拆分并指向对方；两文件的"状态"行保持同步
  - **实施前提**：先通读方案文档；实施中发现与方案冲突的事实，**先更新方案再动代码**
  - 后续每轮追加需求成对记录：设计进方案 §8.x，实施记录进实施文档 §6.x

### 章节取舍原则

- 各章节按需取舍：小修复（1~2 个文件）可省略"设计决策"；不涉及 CSV/常量改动可简化"构建与缓存"；纯数据/地图改动可省略"单元测试"分组
- 但**元信息头、现状调查、验证清单、风险与回滚、改动文件清单**任何计划都不可省
- 编写规范：正文全中文；代码位置写成 `file.py:行号 函数名`；关键机制用表格；方案里的代码片段是"意图示例"而非最终代码，实施时以实际代码为准

## 2. 现状调查

<实施前必须完成的调查，为设计决策提供依据。每个调查点一个 H3 小节。应覆盖：>

<用 `file.py:行号 函数名` 精确到行；机制规则多时用表格（规则 | 依据/位置）。参考 plan_04 §2、plan_06 §2.4。>

### 2.2 <可复用的既有实现>

<先找先例再造新轮子：类似功能的指令/前提/结算/面板怎么写的，能否照抄。参考 plan_06 §2.4"新增指令流程参考"。>

### 2.3 <已知陷阱与硬约束>

<缓存不删不生效、存档兼容钩子、循环导入、编号占用、`buildconfig` 必跑条件等。参考 plan_01 §2.5、plan_10 方案 §2.8。>

### 2.4 <引用全量清单（删改既有字段/函数时必做）>

<grep 穷举所有读写点并列表，作为"改完归零"的验收判据。参考 plan_10 方案 §2.1。>

## 3. 设计决策 <小改动可省略本章>

<每个有取舍的点一小节：选了什么、为什么、弃选方案及原因。多个挂钩/选点时用三列表格（记录/功能 | 选点 | 弃选方案及原因），参考 plan_10 方案 §3.2。>

## 4. 详细改动步骤 <也可命名"实施方案"/"实施步骤">

<按文件或按功能点分 H3 小节，顺序即建议的实施顺序。每小节：>
<- 标题带文件路径与行号锚点，如 `### 4.1 数据结构（Script/Core/game_type.py:505）`>
<- 给出代码片段/CSV 行示例与其落点；新增字段附中文 docstring>
<- ⚠️ cid/效果 id 等编号只是建议值，实施时必须核对空闲号（plan_06 §8.1 教训：建议号已被占用）>
<- 常见配套项自查：常量注册（constant/*、constant_promise）、前提函数、结算函数、口上 CSV、ArkEditor 副本 CSV 同步、旧存档 hasattr 回填（save_handle.py）、Tk 与 Web 两套显示>

## 5. 构建与缓存 <无 CSV/常量/地图改动时可简化或删除>

```bash
# 本机必须用 conda 解释器（裸 python 是 Store 空壳别名）
.conda\python.exe buildconfig.py   # CSV/常量改动后全量重建（data.json / config_def.py / PO）
.conda\python.exe buildpo.py       # 涉及翻译词条时
.conda\python.exe buildmo.py
# 地图改动：删除 data/SceneData data/MapData data/PlaceData data/ScenePath 后跑 init_data.py
```

<注明本次必须跑哪些、为什么（如"改了 4 张 CSV，必须全量 buildconfig"）。>
