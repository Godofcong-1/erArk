### 2.5 已知陷阱与硬约束

1. **前提必须是纯函数**（Plan 24 §2.6-1）：`judge_personal_course_valid` 在前提路径上，新增的「借得到书」判定只读；真正借书只能放在状态机 716 里
2. **716 复用的是全岛共用的行为**（training / exercise / swimming / 各娱乐行为）：不能往它们的效果串里加出勤结算，成年干员娱乐时也走这些行为
3. **`last_attend_period` 也是教室课收益的去重标记**：个人式课与教室课同一节不会并存（一格一门课；必修覆盖后是教室课），共用它不会互相挤占
4. **阅读进度与借阅名额属于图书馆系统**：兴趣课借了书，就和娱乐读书一样占一本、按还书概率归还
5. **阶段起点不入档**：成长停滞（素质 28）期间阶段不推进，解除后按阈值一次长大，这时「本阶段第几天」按阈值算会偏大。与养成数值 3（阶段进度）是同一个近似，见 §7

## 3. 设计决策

### 3.1 体育课与兴趣课计出勤（M1，推荐口径 1）

新增 `growth_handle.settle_course_attend(character_id) -> bool`：
- 只给女儿或学生岗记，守卫照 `settle_attend`；
- 节次内按 `last_attend_period` 去重，同一节只记一次；
- 记上了返回 True。

716 装好体育 / 兴趣课的行为之后调用它。实习课不调，552 已经经 `settle_student_class_gain` 记过。时机与教室课一致：NPC 的结算发生在行为开始时。

| 候选 | 弃选原因 |
| --- | --- |
| 体育 / 兴趣课缺课也不记，两边都不算 | 课表上排的就是课，`<课>`、必修的顶替标记、个人课表都把它当课；第五轮定的口径是「只有课表排了课的节次计出勤」 |
| 往被复用的行为的效果串里加出勤结算 | 这些行为全岛共用（打木桩、下棋），成年干员娱乐时也会走到 |
| 行为结束时再记 | 行为循环没有「结束时」的钩子；教室课同样是在开始时记 |

### 3.2 兴趣课「读书」先借书（M2，推荐口径 2）

- 抽出 `borrow_book_panel.prepare_npc_read_book(character_id) -> bool`：沿用 `check_random_borrow_book` 借书，借到后把书写进 `behavior.book_id / book_name`。401 与 716 共用，401 的行为不变
- 新增只读判定 `borrow_book_panel.judge_can_get_read_book(character_id) -> bool`：手上有借着的书，或书库里有没被借走、读得了、没读完的书（与 `check_random_borrow_book` 的筛选同口径）
- `schedule_handle.judge_personal_course_valid`：兴趣课的行为是读书时，再要求 `judge_can_get_read_book`；借不到书的这一节视为没课，同 Plan 28 的口径
- 716：兴趣课的行为是读书时先 `prepare_npc_read_book`。失败（判定与执行之间书被别人借走）就等 1 分钟、不记出勤，下次决策按没课走

| 候选 | 弃选原因 |
| --- | --- |
| 716 借不到书就等 1 分钟（照搬 401） | 一节课里一分钟一分钟地重试 45 次。401 自己也有这个空转，属读书系统，本轮不改 |
| 借不到就读读过的书、不借 | 绕开借阅名额，图书馆的借还就不成立 |
| 个人课表格子标「无书可借」 | 借阅是随时变的，在周表上标一时的状态会误导 |

### 3.3 养成事件抬头写本阶段第几天（L1，推荐口径 3）

新增 `growth_handle.get_stage_day(character_id) -> int`：本阶段已过的日历天数，即有效成长天数减去本阶段起点，起点为 0 / 90 / 270 / 450，不小于 0。`get_stage_progress` 改用它，数值不变。

抬头写 `get_stage_day + 1`，进入该阶段当天为第 1 天。单位仍是日历天，与养成总览、阶段阈值一致；抬头不加「（日历天）」。

| 候选 | 弃选原因 |
| --- | --- |
| 维持出生以来的总天数 | 「萝莉期第 300 天」读起来是萝莉期过了 300 天，而萝莉期一共才 180 天 |
| 抬头加「（日历天）」 | 抬头是一句点名；单位与养成总览同一套，总览上已写明 |
| 新增字段记下每个阶段的实际起点 | 只有成长停滞才会偏；要改存档结构与三处长大结算，也与养成数值 3 的近似口径不一致 |
