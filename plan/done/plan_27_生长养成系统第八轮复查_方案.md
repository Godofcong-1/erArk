## 1. 目标

1. 幼女的每日娱乐与日程模板不再把人派到还没解锁的场所：黄澄澄游戏室没开放时不抽过家家，日程里排了未开放场所的活动退回自由选择，面板上看得出来
2. 「上课（无课时自习）」去自习时只去已开放的理论教室
3. 全局课表里清空了的那一节，学生按「没课」处理，不去空教室自习、不记出勤
4. 同一节里下课后再开一次实操课，到场学生各记一次出勤，按设计保留（决策 3）：说明文档写明、测试锁住
5. 玩家手动授课拉来的学生到本节下课就走，不耽误下一节
6. 「检查成绩单」在学期中途给得出本学期截至目前的情况，口上与正文对得上
7. 当场爆睡的学生不会被开讲的教师或玩家的授课拉起来听课
8. 小修：个人课表选实习课时周日的重复提示；说明文档里过期的前提数

**验收标准**：
- 全套回归测试通过，新增断言覆盖 §3 每一条；复现脚本（实施文档 §2.0）改前全部命中、改后除 L2（按设计保留）外全部不命中
- `tools/official_event_check.py` 与口上前提校验（`test_talk_data`）通过
- 行为循环测试收敛，出勤人均 ≥ 3 节不变

## 3. 设计决策

### 3.1 日程与幼女默认娱乐查场所开放（M1，推荐口径 4）

新增 `schedule_template_handle.judge_activity_place_open(entertainment_id) -> bool`：取该娱乐的 `place` 交给 `schedule_handle.judge_scene_open`，与寻路的 `wait_open` 同口径。

| 调用方 | 改为 |
| --- | --- |
| `handle_npc_ai.get_chara_entertainment` 幼女分支 | 默认池先滤掉场所未开放的；滤空了（理论上不会，育儿室恒开放）只剩自由玩耍 |
| `schedule_template_handle.apply_schedule_for_child` | need 校验之后再查场所，未开放的时段跳过、保留当天的随机娱乐（退回自由选择），与 need 不过同一种退法 |
| `schedule_template_handle.get_child_slot_activity_text` | need 不过仍写「条件不符→自由选择」；need 过了但场所没开的写「未开放→自由选择」 |
| `schedule_template_panel._select_activity` | 场所未开放的活动在名字后标「未开放」（与年龄标注写在同一对括号里），**仍可选**：模板长期有效，解锁之后自动生效 |

| 候选 | 弃选原因 |
| --- | --- |
| 在 563 这类移动状态机里挡 | 那是通用的「去某处」模块，全岛干员共用；源头在派活动的两处，挡在源头就不会出现空转 |
| 未开放时改写成自由玩耍 | 日程改写的既有约定是「退回自由选择」（保留随机值），另起一种退法会让面板上的说法对不上 |
| 面板上禁选未开放的活动 | 模板是长期设置，玩家常先排好再建场所；禁选只会逼人解锁后回来重排 |

### 3.2 自习的去处只挑已开放的理论教室（M2，推荐口径 5）

561 的回落改为在 `schedule_handle.get_classroom_list(COURSE_TYPE_THEORY)` 里随机挑；这份表空了（不会发生，理论教室一不在解锁表里）才退回原来的全表随机。教师查不到教室时的回落同样受益。

### 3.3 已停课视为这节没课（L1，决策 1）

`schedule_handle.get_course_at` 对班级式课：全局课表那一格（含当天临时课覆盖层）是空的就返回 None。

| 下游 | 改后 |
| --- | --- |
| `class_ai.get_course_stage` / `get_upcoming_course` | 没课 → NONE，交回见学 / 娱乐链；也不会为一节已停的课提前动身 |
| 548 自习结算、`<课>` 标识、CVP `Course` / `CourseType` | 读不到课 → 按「没课」处理（日程活动的自习照旧给收益、不计出勤） |
| 截短规则 B、303 拉人（`judge_student_join_class`） | 那一节没课，不截、不拉 |
| 必修生覆盖（临时课） | 不受影响：覆盖后指向临时课的教室，覆盖层给出的格子非空 |
| 预约在每周课表空着的教室里的实操课 | 不受影响：当天覆盖层给出的格子非空，选修生照旧会来（`judge_sex_class_is_mine` 读的是个人课表本身） |
| 前置修习 `judge_has_sex_skill_course`、同班同学、一键选课 | 不受影响：它们直接读个人课表或 `include_temp=False` 的格子 |
| 教师来不了（格子在、教师为 -1 或缺席） | 不受影响：仍是教室课，降级自习并计出勤 |

### 3.4 实操课每次开课各记一次出勤（L2，决策 3：按设计保留）

用户拍板：每开一次实操课就是一节独立的课，到场学生各记一次出勤是合理的。代码不改：`start_sex_class` 每次开课给到场学生 `settle_attend`、722 给开课后到场的人记一次，都照旧。

- 第五轮修的「每节 +2」是**同一次开课**里 `start_sex_class` 与 10014 各记一次，属重复计数；这里是两次开课，不是一回事
- 说明文档 §10 写明「每次开课单独记一次，按设计」，免得下一轮复查又当成重复计数报上来
- `test_sex_class` 加一条断言锁住：同一节开课 → 下课 → 再开，到场学生出勤 +2
- 原推荐的「按临时课键去重」（`CHILD_GROWTH.last_sex_class_key`、`settle_attend(student_id, class_key)`）不做

### 3.5 玩家授课拉来的学生截到本节下课（L3，推荐口径 6）

`handle_teach` 把学生的听课时长改为 `get_period_left_minute`（对齐开始时刻之后取，节次内给到节末、节次外 45 分钟），与 303 同口径。玩家自己的授课时长不变（45 分钟）：收益由玩家行为的 512 在开讲时就结算过，学生提前离开不影响收益与出勤。

### 3.6 检查成绩单：看过之后给本学期截至目前（M3，决策 2）

- 550：`finished = 待查看标记 and 有成绩单`。有未查看的新成绩单 → 给冻结的那份并清标记；否则 → 现算本学期截至目前（`build_report_card`），标记不动
- 新增养成数值 23「成绩单待查看」（`GROWTH_VALUE_REPORT_PENDING`，有待查看为 1、否则 0），`get_growth_value` 给出
- `check_report_card.csv` 按档位分的 12 条（cid 1000~1003、1006~1013）前提追加 `CVP_A2_Growth|23_E_1`；1004 / 1005 两条通用口上不动。学期中途只出通用口上，不会口上夸上学期、正文却是本学期
- 口上在效果之前输出（§2.3），查看新成绩单时判前提那一刻标记还在，分档口上照常出
- 「更早的 N 个学期可以在养成总览里翻看」按发的是哪份算（实施时补）：发冻结那份时它自己就是历史里最新的一份，N = 历史数 − 1；给截至目前时历史里每一份都更早，N = 历史数。原写法只在发冻结那份时对

| 候选 | 弃选原因 |
| --- | --- |
| 只改正文、口上不动 | 学期中途会出现「口上说上学期优秀、正文是本学期的进行时」 |
| 另写一套「截至目前」的口上 | 需要新写十几条文本；通用口上本来就是给「还没有成绩单」写的，语义相通 |

### 3.7 学生睡着的判定同时看行为（L4，推荐口径 7）

`judge_student_pullable` 的睡觉判定改为「要睡觉标记 or 行为是睡觉」，写法照 `judge_mother_followable`。影响面：303 拉人、玩家授课拉人、授课指令的前提 `student_not_study_in_classroom`，都是「不该把睡着的人拉来」。
